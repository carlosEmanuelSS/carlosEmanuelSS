# 🚀 Projeto em destaque

## SGS-ASP — Sistema de Gestão Social

Sistema web desenvolvido para apoiar a **Ação Social do Planalto (ASP)** na centralização de informações e organização de processos internos.

O projeto nasceu a partir de uma necessidade real da instituição e foi desenvolvido no **Projeto Integrador de ADS do CEUB**.

### Problema

Informações importantes da instituição estavam distribuídas entre diferentes ferramentas, planilhas e registros.

### Solução

Uma plataforma para centralizar:

- cadastro de educandos;
- oficinas e turmas;
- frequência;
- atendimentos;
- indicadores;
- relatórios.

### Stack

`React` `TypeScript` `Vite` `Tailwind CSS` `shadcn/ui` `Recharts`

### O que pratiquei neste projeto

`Levantamento de requisitos` • `Scrum` • `UI` • `React` • `TypeScript` • `Git` • `Deploy`
